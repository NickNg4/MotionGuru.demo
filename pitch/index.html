Phase 0

Preprocessing: from raw footage to clean round data

OCR Timer Detection

Automatically locates and reads the broadcast round timer using EasyOCR. Detects round start/end boundaries without any manual input — works across networks (ESPN, DAZN, Sky Sports).

Intelligent Segmentation

Identifies and discards replays, walk-outs, and between-round breaks by detecting scene transitions and timer absence. Only live-action frames enter the pipeline.

Lossless Round Extraction

FFmpeg extracts each round as a separate video with zero re-encoding — preserving original resolution and bitrate. Metadata (round number, timestamps, FPS) logged to JSON.

Quality Validation

Pre-flight checks verify resolution, frame rate consistency, and codec compatibility before the pipeline commits to processing. Fail-fast on corrupt or unsupported inputs.

This stage is optional — the pipeline can also accept pre-segmented round clips directly.

Phase 1 Deep Dive

Pose Extraction: track every joint, every frame

Smart Calibration

2-phase system: fast 45s scan scores frames for quality (separation, bbox size, sharpness), then selects top-20 frames to build primary fighter templates. Close-up templates enriched separately at 30% blend weight.

Similarity Scoring

Multi-signal identity: OSNet cosine + guard stance bonus + referee pose penalty × lateral zone confidence + shorts color + position bonus. Hungarian assignment for globally optimal pairing.

Intersection-Aware

When fighters clinch (bboxes within 12% of frame width): anchor threshold raised to 0.92, home zone EMA suppressed, Kalman recovery disabled. Prevents identity swaps during close-range exchanges.

1-Euro Smoothing

Adaptive per-keypoint filtering with kinematic-group betas: wrists=1.5 (fast punches), elbows=1.0, head=0.6, shoulders/hips=0.3 (stable posture). NaN-safe; resets on camera cuts.

Phase 2

57 biomechanical features per frame

Speed & Power

Wrist velocity, wrist acceleration, elbow extension rate — the kinematic signature of each punch.

Guard & Defense

Guard openness (L/R/combined), wrist-to-nose distance, elbow tuck angle — defensive posture decoded.

Body Mechanics

Shoulder rotation, hip rotation, torso lean angle, rotational velocities — the kinetic chain in numbers.

Footwork

Stance width, COM velocity, weight distribution — the foundation beneath every punch.

Cross-Fighter

Shoulder distance, closing/separating rate, wrist-to-chin proximity — two fighters as one system.

Data Quality

Binary valid_frame indicator (never z-scored). Forward-fill for ≤3 frame gaps. NaN propagation for longer drops.

Engineering

Real-world boxing footage breaks everything

Fighter Occlusion

Clinches, referee blocking, and camera angles cause complete loss of visibility. Solved with Kalman filter prediction and intersection-aware tracking that raises identity thresholds during close-range exchanges.

Identity Tracking

Broadcast cuts, replays, and similar-looking fighters cause ID swaps. OSNet-x1.0 ReID + multi-template calibration + Hungarian assignment + jump guard maintains identity across the full video.

2D → 3D Inference

Single-camera 2D poses must approximate 3D biomechanics. Confidence tagging (direct / proxy_2d / requires_3d) flags every metric so downstream analysis knows what to trust.

Class Imbalance

Fighters spend ~85% of rounds idle. FocalLoss (γ=2.0) with class weights clamped ≤10, GroupNorm, and careful post-processing prevent the model from predicting idle for everything.

Design Philosophy

Why deterministic beats LLM

LLMs Can't...

Reliably count punch frequencies across 36 minutes of fight data. Maintain consistent thresholds between reports. Track 107 metrics simultaneously without hallucination. Guarantee same input = same output.

LLMs Can...

Turn structured JSON findings into readable prose. Generate natural-language scouting narratives. Adapt report tone for different audiences. Optional prose layer only.

If Claude API goes down, MotionGuru still produces every metric, every strategy, every finding. The scouting report just won't have prose.
